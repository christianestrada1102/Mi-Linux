# Mi Linux

Tu setup Linux, generado a tu medida.

Mi Linux es una plataforma que ayuda a configurar Linux después de instalarlo. El usuario responde un cuestionario sobre su perfil, hardware y forma de trabajar, y el sistema le devuelve un script post-instalación listo para revisar y ejecutar cuando quiera.

La idea nace de un problema real: Linux es poderoso pero su configuración inicial es un caos. Demasiadas distros, tutoriales desactualizados, comandos copiados sin entender, y cada reinstalación implica volver a empezar de cero. Mi Linux convierte ese proceso en una experiencia guiada, clara y reproducible.

## Esta entrega

Este repositorio contiene únicamente el **front-end estático** de la landing page. Es una entrega parcial dentro del contexto de una materia en la Universidad Tecnológica de Chihuahua (UTCH).
